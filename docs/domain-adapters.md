# Domain adapters

The universal runtime stays stable. Adapters provide artifact semantics, relevant tools, likely probes, merge behavior, deterministic checks, and release anchors.

Included profiles:

- generic;
- research;
- formal;
- decision;
- creative;
- software.

All domains retain the same core shape:

```text
exact task → artifact → obligations/cruxes → actions/evidence → integration → synthesis → release
```

Domain-specific executable evidence should outrank generic model judgment when available.
