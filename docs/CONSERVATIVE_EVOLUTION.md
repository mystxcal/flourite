# Conservative evolution and non-regression

## The invariant

V3.5 must not become weaker merely because its state model is richer.

The monotonic-capability invariant is:

> Every material capability of the sparse runtime remains reachable, while new continuity and upper-tail mechanisms are admitted only when they can improve the exact task.

## Preserved control path

Legacy mode retains:

- one baseline;
- sparse issues;
- targeted actions;
- deterministic Pareto filtering;
- evidence integration;
- clean synthesis;
- deterministic checks;
- bounded release;
- explicit software apply.

It does not instantiate v3.5 cognitive objects that could alter scheduling.

## Avoiding control overhead

V3.5 does not allocate a separate model call to each control object.

- orientation emits baseline, Charter, Spine, obligations, cruxes, and initial action slate together;
- workers emit evidence and receipts together;
- checkpoints integrate evidence, update state, and plan together;
- final synthesis emits the final artifact, semantic findings, and Completion Case together;
- release remains one bounded fresh challenge.

The scheduler enforces a control-call fraction for discretionary
non-substantive actions. The resource governor separately protects an
evidence-derived completion path and exposes new work only when progress earns
another horizon.

## Avoiding false sparsity

Sparsity must not become premature convergence. V3.5 preserves upper-tail reach through:

- a mandatory cheap ceiling-sensitivity question inside orientation/checkpoints;
- explicit `summit.mode = "on"`;
- exact-task Summit seeding when active and empty;
- bounded stepping-stone protection;
- reconstruct, reframe, ceiling-audit, and mechanism-graft action types;
- operator-controlled extension;
- sparse fallback when adaptive control fails.

## Avoiding population sprawl

- active cruxes are bounded;
- overlays require behavioral difference;
- normal and hard overlay limits are separate;
- Summit archive and active overlays are separate layers;
- stepping stones have explicit allowances and kill conditions;
- lineages are developed only through the next dependency or falsifier;
- workers do not chat.

## Avoiding evaluator capture

No universal insight scalar owns release. Evidence is scoped and its independence class is explicit. Executable behavior, external evidence, formal checks, deterministic calculations, and real-world observations outrank repeated model consensus when available.

Semantic CI is a regression detector, not an oracle. The Completion Case proves coverage, not truth by itself.

## Avoiding synthesis loss

The Artifact Spine, satisfied obligations, verified substrate, protected insights, prior artifact, and strongest rejected alternative are retained through synthesis. A material loss requires restoration or explicit trade-off.

## Promotion evidence

The optional blind arena compares adaptive and legacy modes under matched solver budgets. It is intentionally outside production execution. Real promotion should use a representative task suite and examine:

- fatal-error rate;
- task-drift rate;
- hard-tail quality;
- useful discoveries lost during synthesis;
- repeated work;
- actions that changed a decision;
- accepted-result cost;
- simple-task overhead;
- performance on tightly coupled and parallel tasks.
